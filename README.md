# Табло — макет умного пешеходного перехода

Веб-приложение, которое показывает два табло:

- **Табло для пешехода** — приближающаяся машина, её скорость, расстояние и время до перехода. Когда переходить опасно, табло краснеет, мигает и подаёт звуковой сигнал.
- **Табло для водителя** — предупреждение о человеке или животном на дороге или у дороги: полоса, где он находится, и расстояние до него.

Работает прямо в браузере телефона, ничего устанавливать не нужно.

## Режимы

**Симуляция** — машины, пешеходы и собаки создаются кнопками или автоматически. Нужна, чтобы проверить поведение табло без выезда на дорогу.

**Камера** — камера телефона распознаёт машины, людей и животных нейросетью COCO-SSD (TensorFlow.js). Расстояние оценивается по высоте объекта в кадре, скорость — по изменению расстояния.

## Как запустить на телефоне

Камера в браузере работает только по HTTPS, поэтому проще всего включить GitHub Pages:

1. В репозитории: Settings → Pages → Source: «Deploy from a branch», выбрать ветку и папку `/ (root)`.
2. Через минуту открыть на телефоне в Chrome `https://<логин>.github.io/tablo/`.
3. Нажать «Запустить с камерой» и разрешить доступ к камере.

На компьютере:

```bash
npm start
```

и открыть `http://localhost:8080`.

## Как поставить телефон

- Телефон стоит неподвижно (штатив) у обочины, в 5–10 м **за** переходом, объективом навстречу машинам. Так в кадр попадают и переход, и подъезжающие машины.
- В «Настройках» укажите число полос, расстояние от камеры до перехода и с какой стороны дороги стоит камера.
- Для точности сделайте **калибровку по человеку**: человек встаёт в полный рост на известном расстоянии от камеры, вы нажимаете кнопку и вводите это расстояние.

## Ограничения макета

- Нейросеть в браузере телефона уверенно видит машину примерно до 30–40 м и обрабатывает несколько кадров в секунду. Скорость оценивается грубо и с задержкой около секунды. Для проверки идеи этого достаточно, для реальной дороги — нет: там нужен радар или лидар.
- Расстояние считается от типичной высоты объекта (легковая машина 1,5 м, человек 1,7 м), поэтому для нестандартных объектов оно неточное.
- Оба табло показываются на одном телефоне. Вывод на два отдельных экрана пока не сделан.
- Макет нельзя использовать как средство обеспечения безопасности на настоящей дороге.

## Как принимается решение

Для пешехода считается время, через которое машина доедет до перехода, и сравнивается со временем на переход дороги:

| Уровень | Условие |
| --- | --- |
| «Машин нет» | движущихся машин нет |
| «Автомобиль далеко» | времени больше, чем нужно на переход + запас + 5 с |
| «Внимание!» | времени чуть больше, чем нужно на переход + запас |
| «Стойте!» | времени на переход не хватает или машина уже не успеет остановиться |
| «Опасность!» | то же, и при этом человек уже на проезжей части |

Для водителя: «у дороги» — жёлтое предупреждение, «на дороге» — красное, «Тормозите!» — если спокойного торможения до человека уже не хватает.

Все пороги меняются в «Настройках».

## Структура

- `js/logic.js` — оценка опасности (чистые функции)
- `js/tracker.js` — дальность по рамке, ведение объектов, сглаживание скорости
- `js/detector.js` — камера и нейросеть
- `js/sim.js` — симулятор
- `js/boards.js`, `js/map.js`, `js/audio.js` — табло, схема дороги, звук
- `vendor/` — TensorFlow.js и COCO-SSD
- `tests/` — тесты (`npm test`)
